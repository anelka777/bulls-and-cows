# DESIGN

Игра Bulls and Cows. Вся игровая логика написана как набор чистых функций (`src/logic`), без классов и без зависимости от DOM. Интерфейс (`src/ui`) только вызывает эти функции и рисует результат.

## 1. Структуры данных и алгоритмы

### Состояние игры

Состояние это неизменяемый объект `GameState` (`src/logic/game.ts`):

- `settings` (`{ length, base }`);
- `secret` (строка, например `'0123'`);
- `history` (массив записей `{ guess, bulls, cows }`);
- `startedAt` и `finishedAt` (метки времени, `finishedAt === null` пока игра идёт).

Секрет хранится **строкой**, а не числом, чтобы не терять ведущие нули (`0123`) и чтобы в hex были буквы. Строку можно превратить в массив символов через `[...secret]` и обрабатывать методами массивов.

История это **массив**: попытки идут по порядку, нужен только перебор и добавление в конец. Новая попытка добавляется как `[...state.history, entry]`, старый массив не меняется. Функция `submitGuess` возвращает новый объект состояния и статус (`accepted`, `invalid`, `duplicate`, `finished`), так что UI не мутирует состояние.

Время передаётся в функции параметром (`now`), а не берётся через `Date.now()` внутри. Поэтому логика остаётся чистой и тестируется без подмены часов.

### Рекорды

Рекорды это массив записей `{ attempts, timeMs, date }`. Для каждой пары «длина + система счисления» ведётся отдельный список, ключ в `localStorage` строится функцией `recordsKey` (`bulls-and-cows:records:<length>:<base>`). `addRecord` создаёт копию массива, сортирует по числу попыток и при равенстве по времени, оставляет топ-N. Данные из `localStorage` читает `parseRecords`: она безопасна к пустому значению, битому JSON и неправильным записям.

### Алгоритм `evaluateGuess`

Цифры секрета и попытки уникальны, поэтому достаточно двух проходов методами массивов:

1. `bulls` это число символов попытки, совпавших с секретом по индексу (`filter` по `(char, i) => char === secret[i]`).
2. `common` это число символов попытки, которые вообще есть в секрете (`filter` + `includes`).
3. `cows = common - bulls`: быки тоже входят в `common`, поэтому вычитаются.

Обе строки приводятся к нижнему регистру, чтобы в hex `A` и `a` были одной цифрой. Ручных циклов и счётчиков нет.

### Алгоритм `countPossibleSecrets`

Число секретов без повторов это число размещений P(base, length) = base · (base-1) · ... · (base-length+1). Рекурсивная связь: `f(length, base) = base * f(length - 1, base - 1)`. База: `length === 0` даёт 1, а при `length > base` результат 0. Функция обёрнута в универсальную `memoize` (`src/logic/memoize.ts`), которая хранит результаты в `Map` по ключу из аргументов. Рекурсия вызывает уже мемоизированную версию, поэтому в кэш попадают и промежуточные шаги, и повторные открытия настроек не пересчитывают значение.

## 2. Сложность

Пусть `n` это длина секрета (`length`), `b` это основание (`base`).

| Функция                | Сложность                                  | Обоснование                                                                                                                                                                                                      |
| ---------------------- | ------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `generateSecret`       | O(n · b)                                   | `n` рекурсивных шагов, на каждом пул из не более `b` цифр фильтруется за O(b), создавая новый пул без выбранной цифры.                                                                                           |
| `evaluateGuess`        | O(n²)                                      | Два прохода `filter` по `n` символам, во втором внутри `includes` проходит по `n` символам секрета. При `n ≤ 6` это несколько операций; через `Set` можно снизить до O(n).                                       |
| `isValidGuess`         | O(n)                                       | Приведение к нижнему регистру и разбор строки, `every` с проверкой алфавита и `Set` для поиска повторов, каждый шаг за O(n). Проверка алфавита сводится к поиску в строке длиной не более 16, то есть константа. |
| `countPossibleSecrets` | O(n) при первом вызове, O(1) при повторном | Рекурсия делает ровно `n` шагов, каждый это одно умножение. Результат кэшируется в `Map`, повторный вызов с теми же аргументами возвращает значение за константное время.                                        |

## 3. Принципы чистого кода

- **Чистые функции без побочных эффектов.** Все функции в `src/logic` зависят только от аргументов: `evaluateGuess`, `isValidGuess`, `submitGuess`, `addRecord`. `generateSecret` получает источник случайности параметром, а `submitGuess` время, поэтому всё детерминировано и тестируется без моков глобальных объектов.
- **Разделение ответственности.** Логика (`src/logic`) не знает про DOM и `localStorage`. Работа с DOM собрана в `src/ui`, обращение к `localStorage` только в `src/ui/storage.ts`.
- **Одна функция одна задача.** `isValidGuess` проверяет попытку, `evaluateGuess` считает быков и коров, `submitGuess` склеивает их и обновляет состояние. Мелкие помощники (`pickDigits` в `generateSecret.ts`, `isRecord` в `records.ts`, `byAttemptsThenTime`) вынесены отдельно.
- **Осмысленные имена.** `availableLengths`, `clampLength`, `createDigitValidator`, `parseRecords`: по имени понятно, что делает функция и что возвращает.
- **DRY.** Валидатор цифр `createDigitValidator` написан один раз и используется в `isValidGuess` (`src/logic/isValidGuess.ts`) и в фильтрации ввода (`src/ui/game.ts`). Универсальная `memoize` не привязана к конкретной функции.
- **Иммутабельность.** Состояние и списки не изменяются, а пересоздаются (`[...history, entry]`, `{ ...state }`, `[...records, record].sort(...)`).
- **Явные типы вместо «магических» значений.** Результат `submitGuess` описан типом `SubmitStatus`, а настройки типом `Settings`.
- **Защита от ошибочных данных.** `parseRecords` не падает на битом JSON, а `generateSecret` бросает `RangeError`, если длина больше основания.
- **Безопасный DOM.** Элементы создаются через `createElement` и `textContent` (хелпер `el` в `src/ui/dom.ts`), `innerHTML` не используется.
